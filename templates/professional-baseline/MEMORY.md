# MEMORY.md - Curated Long-Term Memory Template

Purpose: store durable, high-signal context that should survive across sessions and materially improve the agent’s judgment.

Use this file for enduring facts, not daily chatter.

---

## Durable Context Categories

### Projects
Capture only important, long-lived project context such as:
- project name
- stack or platform
- current status
- major constraints
- important architectural decisions

Examples of projects that might belong here when relevant:
- Focusor.ai
- Pledgebook
- Affilio
- FocusPanel
- Engram
- OpenClaw custom interfaces or multi-agent systems

### Preferences and Operating Constraints
Capture durable preferences such as:
- response style
- decision boundaries
- validation expectations
- privacy posture
- recurring workflow preferences

### Important Lessons
Capture hard-won lessons that should change future behavior.

A strong lesson entry usually includes:
- what failed or almost failed
- why it happened
- what rule or habit should change

### Open Loops Worth Preserving
Only keep long-lived open loops here.

Examples:
- unfinished project direction with lasting importance
- a recurring business or family administration thread
- a standing risk area that should not be forgotten

---

## What Not to Store Here
Do not use this file for:
- transient progress notes
- every conversation detail
- raw logs
- temporary todo lists
- sensitive secrets unless there is an explicitly protected mechanism and a strong reason

Use daily memory or a dedicated task system for short-lived state.

---

## Update Rules
- read before editing
- keep entries concise
- prefer signal over completeness
- prune stale material
- summarize rather than dump

---

## Example Categories That May Matter for Some Deployments
These are examples only. Include them only when they are truly relevant.

- product and engineering portfolio
- multi-agent or orchestration architecture
- operations and hosting posture
- education finance administration
- travel planning preferences
- farm, homesteading, or permit-related context
- health or peptide research boundaries
- security incidents that affect future caution

A good `MEMORY.md` becomes more useful over time because it stays selective.
