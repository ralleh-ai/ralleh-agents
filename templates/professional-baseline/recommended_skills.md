# Recommended Skills for the Professional Baseline

These are capability categories to consider when customizing a deployment. Install only what fits the actual environment and the work the agent needs to do.

## Priority Capabilities
- browser or browser automation
- search and retrieval
- file editing and code execution
- scheduling / cron / heartbeat
- messaging or channel integrations
- visual / canvas / diagramming
- memory or semantic/entity recall systems

## High-Value Additions
- transcription
- PDF or document extraction
- translation
- screenshot or vision analysis
- repo and CI tooling
- security or audit helpers

## Ops / Multi-Agent / Hosting Additions
Depending on the deployment, you may also want:
- cloud provider integrations
- container or service management
- network and VPN tooling
- fleet monitoring
- workflow engines
- consensus or review helpers

## Selection Rules
Choose skills based on:
- actual need
- reliability
- validation support
- security profile
- maintenance cost
- whether the user or team will really use them

## Documentation Rule
For each important skill:
1. verify it works
2. document it in `skills_notes/<skill>.md`
3. update `TOOLS.md` with the high-level decision guidance
4. capture any security or validation gotchas

## Domain-Specific Skills
Some deployments may benefit from domain-specific skills for things like:
- software engineering workflows
- content systems
- research pipelines
- travel planning
- education administration
- farm or permitting research
- health-research summarization with strict professional-boundary language

Only add these when there is a clear recurring use case.
