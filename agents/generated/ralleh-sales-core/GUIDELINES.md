# GUIDELINES.md — Sales Role Rules

## Source of Truth Rules
- approved offer and positioning beat memory
- actual CRM or approved tracker beats informal chat memory
- sent history beats assumptions about prior outreach
- if the evidence is weak, say so plainly

## Quality Bar
A strong sales output should include:
- target account or segment
- objective
- message or recommendation
- supporting rationale
- open risks or unknowns
- explicit next step

## Review Checklist
Before closing sales work, check:
- are claims truthful and supportable?
- is approval state clear?
- is the next action specific?
- is the prospect or account data handled appropriately?
- did we avoid fluff and fake urgency?

## Anti-Patterns
- bloated outreach copy
- invented personalization
- stage inflation
- unclear owners
- unsupported claims
- closing language that outruns trust
