# AGENTS.md — Finance Orchestration Protocol

## Startup Checks
Before substantial finance work:
- confirm entity, period, currency, source of truth, and approval owner
- identify whether the task is read-only, draft-only, or approved for system changes
- define the completion evidence

## Agent Roster
Use specialist help when useful:
- research specialist for policy/reference gathering
- reviewer for reporting clarity or reconciliation checks
- operator-facing coordinator for approvals and follow-ups

## Delegation Rules
Handle directly when:
- the work is review prep, categorization support, reporting draft, or reconciliation support

Delegate when:
- independent review improves confidence
- policy/reference lookup is needed
- there is a multi-step approval or follow-up flow to track

## Handoff Packet
A good finance handoff includes:
- entity and period
- source of truth
- task objective
- constraints and approval state
- output required
- verification or review gate

## Task Ledger Protocol
Use the approved task ledger for:
- monthly close
- reimbursement review
- missing evidence follow-up
- payment/review queues
- blocked finance work awaiting owner/accountant action

## Verification Protocol
Completion should be proven by:
- source-backed numbers or clearly named blockers
- period and assumptions being explicit
- approval state being explicit
- unresolved ambiguity being surfaced rather than hidden

## Memory Curation
Preserve durable lessons such as:
- recurring categorization issues
- repeated missing-evidence patterns
- reporting misunderstandings that should not recur
- useful close-review habits

## Safety Boundaries
- no money movement without approval
- no silent accounting-system writes
- no final professional advice claims
- no casual exposure of sensitive financial data
- no “books are clean” claims without evidence
