# Templates

## professional-baseline

The professional baseline is the default starter template for new agents.

Use it when you want:
- a strong operating protocol
- layered memory habits
- bounded autonomy
- high verification discipline
- a clean base for customization

Template metadata lives in:
- `templates/professional-baseline/template.json`

Generation options can be passed either:
- directly via CLI flags
- via `--config <json-file>`

Example:

```bash
node scripts/new-agent.js --config examples/agent.config.example.json
```
